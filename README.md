# Zvereva_Python_homework
Калькулятор

Это простое приложение-калькулятор. Оно позволяет выполнять базовые арифметические операции: сложение, вычитание, умножение и деление.

Как войти?

Просто зайти на сайт: "https://bonigarcia.dev/selenium-webdriver-java/slow-calculator.html"

Тестирование:

Класс для страницы калькулятора находится в файле: calculator.py.
Тесты находятся в файле: calculator_test.py. 
Чтобы запустить тесты и сформировать отчет, выполните: allure serve allure-results

Где посмотреть отчет?

Результаты тестов можно посмотреть в папке "allure-result", содержащий подробную статистику и результаты выполнения тестов.


Магазин

Как войти?

Просто зайти на сайт: "https://www.saucedemo.com/"

Тестирование

Класс для страницы магазина находится в файле: shopping_cart_page.py.
Тесты находятся в файле: test_shopping_cart.py. 
Чтобы запустить тесты и сформировать отчет, выполните: allure serve allure-results

Где посмотреть отчет?

Результаты тестов можно посмотреть в папке "allure-result", содержащий подробную статистику и результаты выполнения тестов.
